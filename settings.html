📘 Tentang MBG AI

MBG AI adalah sistem berbasis Artificial Intelligence untuk mendeteksi makanan dan menganalisis kandungan nutrisi.

Sistem menggunakan model YOLOv8 untuk object detection dan FastAPI sebagai backend server.

Website ini dibuat untuk membantu proses analisis makanan pada program MBG agar lebih cepat dan efisien.
